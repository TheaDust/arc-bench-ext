REQ-7.7 Create or inspect wishlists
"Wishlist"(role=link) opens saved collections, each represented by "{wishlist title}"(role=listitem) with a named opening entry and Edit and Delete actions. Clicking "Create new wishlist"(role=button) opens "Create new wishlist"(role=dialog), where "Name"(role=textbox) and "Save"(role=button) create exactly one Holiday Picks listitem. Favorites may similarly be created empty for rename and delete prerequisites. Opening seeded "Favorites"(role=link) shows its membership-bearing "Hummingbird wishlist t-shirt"(role=listitem) with Remove and Add to cart actions.

For wishlist with product membership: No source-defined authenticated flow adds products to a wishlist; seed only these membership-bearing Favorites objects. Rename/delete tests create an empty Favorites via the in-scope UI instead.

For empty wishlist: Created through REQ-7.7. Favorites and Holiday Picks are isolated to scenario-owned accounts.

English action names are case-insensitive. Global navigation remains available across pages; each mutation affects the selected business identity.
SCN-REQ-7.7-01 Inspect seeded wishlist and products
{"Given":"Verified wishlist_view_user has seeded Favorites containing Hummingbird wishlist t-shirt.","When":"Sign in, open Wishlist from My account, then activate Favorites.","Then":"Favorites is visible in the collection list; opening it shows the named product listitem and its Add to cart action."}
SCN-REQ-7.7-02 Create Holiday Picks wishlist
{"Given":"Signed-in wishlist_create_user has opened Wishlist.","When":"Click Create new wishlist; enter Holiday Picks in Name within its dialog and click Save.","Then":"Exactly one Holiday Picks collection appears with Edit and Delete actions."}
TEST
// requirement: REQ-7.7

test("REQ-7.7: Inspect seeded wishlist and products", async ({ page }) => {
  await home(page); await wishlistPage(page, 'wishlist_view_user'); const favorite = wishlist(page, 'Favorites'); await expect(favorite).toBeVisible(); await action(favorite, 'Favorites').click();
  const product = wishlistProduct(page); await expect(product).toBeVisible(); await expect(product).toContainText(WISH_PRODUCT); await expect(action(product, 'Add to cart')).toBeVisible();
});

test("REQ-7.7: Create Holiday Picks wishlist", async ({ page }) => {
  await home(page); await wishlistPage(page, 'wishlist_create_user'); await action(page, 'Create new wishlist').click(); const dialog = page.getByRole('dialog', { name: 'Create new wishlist', exact: true }); await expect(dialog).toBeVisible();
  await dialog.getByRole('textbox', { name: 'Name', exact: true }).fill('Holiday Picks'); await action(dialog, 'Save').click(); await expect(wishlist(page, 'Holiday Picks')).toHaveCount(1); await expect(wishlist(page, 'Holiday Picks')).toBeVisible();
  for (const name of ['Edit', 'Delete']) await expect(action(wishlist(page, 'Holiday Picks'), name)).toBeVisible();
});


REQ-7.8 Rename or delete a wishlist
For wishlist_rename_user or wishlist_delete_user, the UI-created "Favorites"(role=listitem) offers scoped "Edit"(role=button) and "Delete"(role=button). Edit displays Favorites in "Name"(role=textbox); replacing it with Holiday Picks and clicking "Save"(role=button) leaves one Holiday Picks and no Favorites. Delete instead removes Favorites from the collection list.

English action names are case-insensitive. Global navigation remains available across pages; each mutation affects the selected business identity.

REQ-7.11 Delete only the selected wishlist
For UI-created "Favorites"(role=listitem) and "Holiday Picks"(role=listitem) under wishlist_delete_user, "Delete"(role=button) scoped to Favorites removes only that collection. Holiday Picks remains exactly once and its "Holiday Picks"(role=link) still opens the surviving wishlist with a Holiday Picks heading, independent of list ordering.

English action names are case-insensitive. Global navigation remains available across pages; each mutation affects the selected business identity.
SCN-REQ-7.11-01 Delete only the selected wishlist
{"Given":"Signed-in wishlist_delete_user has created empty Favorites and Holiday Picks collections through UI.","When":"Click Delete within Favorites, confirm deletion, then activate the surviving Holiday Picks link.","Then":"Favorites disappears, Holiday Picks remains exactly once, and its opening link displays the surviving wishlist."}
TEST
// requirement: REQ-7.11

test("REQ-7.11: Delete only the selected wishlist", async ({ page }) => {
  await home(page); await wishlistPage(page, 'wishlist_delete_user'); await createWishlist(page, 'Favorites'); await createWishlist(page, 'Holiday Picks');
  await confirmDeletion(page, action(wishlist(page, 'Favorites'), 'Delete')); await expect(wishlist(page, 'Favorites')).toHaveCount(0);
  const remaining = wishlist(page, 'Holiday Picks'); await expect(remaining).toHaveCount(1); await expect(remaining).toBeVisible(); await expect(action(remaining, 'Holiday Picks')).toBeVisible();
  await action(remaining, 'Holiday Picks').click();
  await expect(page.getByRole('heading', { name: 'Holiday Picks', exact: true })).toBeVisible();
});
