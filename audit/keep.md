# Keep 生命周期与标签一致性扩展

当前合并修订 `2026-11-08-keep-bookstack-lifecycle-interactions`，父修订 `2026-11-07-bookstack-lifecycle`。Keep 为 **22 条原子需求、49 个场景**；其中本矩阵覆盖生命周期组件 `2026-11-08-keep-lifecycle` 的 18 条需求、41 个场景（原 16 条需求、33 个场景的 ID、步骤 ID 和标题保留，新增 2 条原子需求、8 个场景）。组合约束需求 REQ-6.1–6.4 及其 8 个场景见 [interactions.md](interactions.md)。逐场景原文与实际断言行见 [keep.json](keep.json)。

## 本轮扩展

| 需求 | 新增场景 | 观察点 |
| --- | --- | --- |
| REQ-2.3 | 重命名笔记 | 同一对象更新标题/正文、动作名、固定分区和标签过滤；无旧副本；其他笔记保留 |
| REQ-2.10 | 恢复活跃笔记 | 逐条 Restore；保留正文、置顶、实际背景和标签；其他垃圾箱笔记不变 |
| REQ-2.10 | 恢复归档笔记 | 从 Archived 删除后恢复到 Archived；取消归档后重新进入标签视图 |
| REQ-2.11 | 永久删除确认/取消 | 只删目标；其余活跃/归档/已删笔记保留；取消后仍能恢复 |
| REQ-3.3 | 跨三种状态重命名标签 | 所有可见标签和恢复后的成员关系同步；不改变生命周期状态 |
| REQ-3.3 | 跨三种状态删除标签 | 不删笔记、不丢其他标签；恢复后不复活旧标签；选择器同步 |
| REQ-4.1 | 生命周期搜索 | 大小写无关地搜索正文；排除归档/已删；恢复后重新命中；无关项保持排除 |

所有对象均从 UI 创建，不要求历史笔记、私有存储或固定时钟。新动作、确认框和恢复去向均写入需求。每场景使用独立数据；单场景包含正向状态、反向缺失、对照对象或刷新检查。

## 验证与保留边界

按用户要求，本轮不执行浏览器/合同/应用测试。仅进行本题和 BookStack 的类型检查、YAML 身份与引用、测试标题一一对应和静态语义核对。新增行为尚无真实应用可行性或通过率证据，原有浏览器合同记录属于历史版本。父矩阵与验证状态见 [父版本记录](../validation/history/2026-11-07-bookstack-lifecycle/README.md)。

既有 KEEP-10 至 KEEP-12 的键盘/图标/视觉/设置覆盖和文本/空集合表示风险保持未决；浅绿色观察沿用原有像素阈值边界。旧分数不能迁移至本版。
