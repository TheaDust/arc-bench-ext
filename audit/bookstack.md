# BookStack 需求与测试逐场景审查

完整阅读并核对 **26 条原子需求、49 个场景**、继承描述、全部 spec、helpers、list-cap 和公共控件合同。逐场景的当前 Given/When/Then 原文、测试行、实际动作/断言以及独立审查结论见 [bookstack.json](bookstack.json)。

原 24 条原子需求、35 个场景的身份、标题和既有断言保持不变；2026-11-07 的生命周期扩展新增 **2 条原子需求、14 个场景**，覆盖已发布页面删除、章节删除、书架书籍成员、删除/重命名后的跨视图一致性、草稿发布与隐私、多用户收藏/最近浏览隔离。扩展需求与测试共同版本化，旧分数不能直接混算。

## 定向修订

- **BOOK-01：未声明的导航结构。** 原 helper 要求公共链接必须处于同时包含 Books/Shelves 的 navigation landmark。现在优先使用实际存在且身份明确的导航；没有该结构时只接受唯一的同名公共链接。重复动作仍严格失败，不使用 `.first()`。
- **BOOK-02：重复普通文本。** 允许页面多个位置显示同一正确昵称或描述；只计可见普通文本。Recent Drafts 的“可见标题恰好一次”也只计可见副本。对象和动作仍按明确身份检查。
- **BOOK-03：富文本字段。** 需求允许 `role=textbox` 的 rich-text Description 和页面正文；`toHaveValue` 会拒绝合法 contenteditable。现在读取原生字段 value 或 contenteditable 的公开 innerText，同时要求正确 textbox 角色和保存内容。
- **BOOK-04：列表上限。** 标准表格的列标题行不再计作业务记录，保留 listitem/data row、实际条数上限及对象唯一性。
- **BOOK-05：键盘访问。** `focus()` 不证明 Tab 可达。Shelves/Books 的检查现在遍历真实 Tab 顺序，补上 Books 原来缺失的可见/键盘结果断言。
- **BOOK-06：空集合与删除。** 删除/取消收藏后先确认命名集合语义上存在且唯一，再检查目标缺失。允许合法的零面积空区域；隐藏或缺失区域仍失败。Book 删除补确认按钮与即时删除检查，Remember Me 补可见检查。
- **BOOK-07：父关联唯一性。** Shelf 创建的 Book 在该 Shelf 的 Book list 中须恰好一次且可见。
- **BOOK-08：保留明确角色。** New Shelf、Create New Book、发布页面及 Chapter 的明确 button 角色不再被通用 button/link 联合定位放宽。源文允许等价 link 的入口继续接受。
- **BOOK-10：修改与取消的持久状态。** 保存重命名后，列表有一个新名称且旧名称消失，防止复制新对象冒充修改；Cancel 后重载并重开 metadata，确认原值仍保存。
- **BOOK-12：生命周期与关系一致性。** 删除页面/章节/书籍/书架不只检查当前列表，还检查父/子对象、其他章节、首页 Recently Updated、收藏和最近浏览；取消路径保留原对象。草稿发布不产生重复页面，草稿标题不出现在匿名或其他账号的 Page list、My Recent Drafts 或首页可见文本中。书架成员编辑只改变该书架关联，不移除全局书籍或其他书架关联。

## 扩展场景与失败模式

| 需求 | 新增场景 | 主要失败模式 |
| --- | --- | --- |
| REQ-4.4 | 删除书架后保留书籍 | 删除书架时级联删除书籍；书籍从全局 Book list 消失 |
| REQ-4.5 | 编辑书架书籍成员 | 移除书籍等于删除；只更新单向关联；多书架串味 |
| REQ-5.4 | 重命名书籍的全局传播 | 只改详情标题，列表/收藏/最近浏览仍旧名 |
| REQ-5.5 | 删除书籍级联章节和页面 | 只删书，章节/页面成为孤儿；首页/收藏残留 |
| REQ-6.1 | 发布草稿 | 发布后草稿仍在 Recent Drafts；重复页面；匿名不可见 |
| REQ-6.1 | 草稿仅作者可见 | 匿名/第二账号能看到标题或打开编辑器 |
| REQ-6.4 | 保存页面编辑 | 编辑器状态变了，阅读页/列表/首页未更新 |
| REQ-7.1 | 最近浏览去重与隔离 | 同一对象多条；他人浏览混入我的列表 |
| REQ-8.1 | 收藏按用户隔离与删除清理 | 收藏全局共享；删除对象后首页残留 |
| REQ-9.1 | 编辑更新 Recently Updated | 只有新建才更新；旧标题仍显示 |
| REQ-10.1 | 删除已发布页面（确认/取消） | 只从 Page list 删除；收藏/最近浏览/首页残留；取消也删除 |
| REQ-10.2 | 删除章节（确认/取消） | 章节删除但页面泄漏；误删其他章节；取消无效 |

## 保留的边界

- **BOOK-09：描述级覆盖。** 首页 search input、封面/默认模板与富文本格式、完整收藏页、dashboard activity 的更多分支等仍没有完整的独立场景或固定观察合同。49 场景不等于全部描述能力已验证。
- **BOOK-11：未决公共作用域。** Book 的同名 parent entry 没有明确区分 breadcrumb/侧栏多副本；详情正文的归属范围和 Tags 的显示序列化语义也未充分规定。没有为解决它们任取第一项或新增定位专用 ARIA 容器。
- **BOOK-13：参考实现边界。** 14 个扩展场景在一个本地参考实现上执行；该实现由既有生成应用补充页面/章节删除 UI 与第二账号种子得到，不是 ShallowCode 新生成的候选应用，也不是官方完整应用通过率。

本轮 **13 类发现：9 类定向修复、2 类明确保留、2 类扩展记录**。原有需求身份和标题保持不变；新增需求/场景/测试身份见 `revision.json`。公共 `public-controls.ts` 保持原样；BookStack 题内有 26 个正式 spec 文件（另含 helpers 与 support）。
